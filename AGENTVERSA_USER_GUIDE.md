# AgentVersa User Guide

## Open the application

From `legalverse-k17-analysis`, run `npm install` once and `npm run dev`. Open the URL shown by Vite.

## Use the dashboard

Select **Open research dashboard** in the top bar. The overview shows only records currently in the browser store. Dimension rows show `Not evaluated` when no reviewed scores exist. Scenario search filters by identifier or title.

## Interpret research records

Predictions are not observations. A prediction can be frozen to preserve its original text; an actual response must be recorded separately. Pending observations are not performance results. Comparisons require sufficient evidence and may be classified as not comparable or insufficient evidence.

## Evidence and claims

The current prototype provides the collections and analytics foundations for evidence and claims. Enter only source-backed records in a future data-entry workflow. Keep supporting and contradictory relationships visible and review unverified material before relying on it.

## Export and limitations

Select **Export JSON** to download the current store with a generation timestamp and methodology note. Browser local storage is local and non-confidential. The application does not authorize legal, administrative, disclosure, or operational decisions.
