# Version 1 vs Version 2 Experimental Framework

Version 1 remains the baseline design document. Version 2 remains a proposal in `agent-design/version-2-proposal.md`; the repository does not contain verified Version 2 runs.

The research store includes an experiment collection for planned, ready, running, completed, awaiting-evaluation, reviewed, and invalid/excluded runs. A valid paired comparison must record the same scenario packet, equivalent instructions, comparable model settings, prompt versions, run number, and any fairness-affecting differences.

Score differences should be calculated as V2 minus V1 only when both sides have reviewed scores. Descriptive summaries must be separated from statistical conclusions. No significance claim or superiority claim is made by the current dashboard.
